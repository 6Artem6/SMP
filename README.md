# СМП (SMP) — Библиотека генерации сменных многогранных пластин для КОМПАС-3D

**СМП (Сменные Многогранные Пластины)** — встраиваемый C++ плагин (библиотека `.rtw`) для САПР **КОМПАС-3D** (основан на Kompas API v5 и v7). Модуль предназначен для автоматизированного проектирования и формирования 3D-геометрии режущих пластин классических и специальных форм с целью последующей 3D-печати твердым сплавом (аддитивное производство) и инженерного анализа.

---

## Назначение проекта
Проект решает задачу быстрого автоматизированного проектирования режущего инструмента напрямую в рабочей среде КОМПАС-3D. 

Вместо ручного построения сложных пространственных поверхностей плагин автоматически генерирует точную твердотельную 3D-модель пластины на основе пользовательских параметров или встроенных математических уравнений резания. Полученные модели используются для последующего экспорта средствами КОМПАС-3D на 3D-печать (спекание твердым сплавом) и проведения анализа прочности/газодинамики.

---

## Ключевые возможности и Сценарии работы

### 1. Стандартная геометрическая форма (Параметрический режим)
Построение классических форм пластин по заданным геометрическим размерам через диалоговую форму плагина.
- **Управляемые параметры:** Длины граней, внешний и внутренний диаметры, толщина, параметры фасок, скругления вершин, подрезы, углы наклона и углы резания (задние/передние углы).

### 2. Специальная геометрия по параметрам резания (Формульный режим)
Построение пластин сложной нетиповой формы, геометрия которых рассчитывается исключительно по математическим уравнениям, зашитым в код C++ ядра.
- **Парадигма:** Параметры процесса резания на входе ➔ расчет пространственного профиля по зашитым формулам в C++ ➔ построение итоговой твердотельной модели в КОМПАС-3D.
- Все ключевые размеры и контрольные точки профиля пересчитываются и контролируются математическим аппаратом ядра автоматически.

## Архитектура и Технологический стек

- **Язык & Стандарт:** C++ (Visual Studio / MSVC)
- **API САПР:** **Kompas API v5 & v7** (COM / C++ SDK)
- **Формат модуля:** Встраиваемая библиотека КОМПАС (`.rtw` / Dynamic Library)
- **Интерфейс:** Встроенная диалоговая форма внутри КОМПАС-3D (без внешних файловых конфигураций)
- **Экспорт данных:** Выполняется штатным функционалом КОМПАС-3D (в форматы для CAM-систем и 3D-печати)

## Сборка и Подключение

### Требования
- **ОС:** Windows
- **IDE:** Microsoft Visual Studio (с поддержкой C++)
- **САПР:** КОМПАС-3D с установленным SDK (Заголовочные файлы и библиотеки Kompas API)

### Шаги сборки
1. Открыть файл решения `*.sln` в **Visual Studio**.
2. Убедиться, что в настройках проекта указаны корректные пути к заголовочным файлам и библиотекам SDK КОМПАС-3D.
3. Скомпилировать проект в режиме `Release`.
4. В результате сборки формируется файл библиотеки библиотеки КОМПАС-3D с расширением `.rtw`.

### Запуск в КОМПАС-3D
1. Запустить КОМПАС-3D.
2. Перейти в меню: **Сервис ➔ Сервисные утилиты (или Библиотеки) ➔ Подключить библиотеку...**
3. Выбрать собранный файл `.rtw`.
4. Из появившейся формы ввести параметры или выбрать режим расчета по формулам резания и нажать **«Сгенерировать»**.
