# SMP

Проект SMP — инструмент генерации сменных многогранных пластин для токарных/фрезерных (и других) инструментов на основе параметров формы или математических формул параметров резания.

## Краткое описание

Проект предоставляет два основных сценария работы:

1. Формирование стандартных сменных многогранных пластин по параметрам формы.
2. Формирование пластин по математическим формулам параметров резания.

Цель — дать гибкий инструмент для быстрой генерации геометрии режущих пластин по набору параметров или по аналитическим формулам, пригодной для последующего экспорта в CAD/CAM или для анализа.

## Особенности

- Поддержка двух сценариев генерации: параметрического (шаблонные/стандартные пластины) и формульного (пластины по аналитическим формулам).
- Конфигурируемые параметры формы и резания.
- Экспорт сгенерированной геометрии в формате, указанном в настройках (пример: OBJ/STL) — настройка формата экспорта зависит от реализации в проекте.

## Сборка

Требования:

- Компилятор C++ с поддержкой C++17 (GCC, Clang, MSVC)
- CMake (рекомендуется)

Пример сборки с помощью CMake:

```bash

cd build
cmake ..
cmake --build . --config Release
```

Если проект использует другие системы сборки — укажите их в CMakeLists.txt или README дополнительно.

## Использование

Ниже приведены примерные команды запуска. Параметры и имена исполняемых файлов уточните в вашем проекте.

1) Сценарий: стандартные сменные многогранные пластины

```bash
./smp --mode standard --shape-file examples/standard_shape.json --output out/plate_standard.obj
```

Параметры, которые обычно ожидаются в этом режиме:
- геометрические параметры пластины (диаметр, угол при вершине, длина режущей кромки и т.п.)
- настройки фасок/скруглений
- разрешение сетки/уровень детализации

2) Сценарий: пластины по математическим формулам параметров резания

```bash
./smp --mode formula --formula "r(t)=...; z(t)=..." --t-range 0,1 --output out/plate_formula.obj
```

В этом режиме можно задавать функции, описывающие профиль или параметры резания, диапазон параметра и шаг дискретизации.

## Форматы входных данных

- JSON/YAML/текстовые файлы с набором параметров для стандартных пластин.
- Простые текстовые формулы или скриптовые выражения для формульного режима (уточните синтаксис в проекте).

## Форматы выходных данных

Сгенерированные геометрические модели можно экспортировать в распространённые форматы (OBJ/STL/) — уточните доступные форматы в коде и настройках проекта.
